# 🏆 DNA DOS CAMPEÕES

## 🚩 Sobre o projeto
Este projeto é uma análise profunda dos últimos 10 campeões da NBA, buscando identificar padrões, contrastes e elementos comuns entre equipes vencedoras — e assim responder à pergunta:

**O que realmente define um campeão?**

---

## 📖 Minha motivação

Como fã da NBA, sempre me perguntei qual é a verdadeira essência de um time campeão.  
Os estilos tão diferentes das equipes vencedoras sempre alimentaram essa curiosidade.

De um lado, a dinastia do **Golden State Warriors**, com um estilo revolucionário baseado em velocidade, movimentação constante de bola e um volume absurdo de arremessos de três — liderados pela icônica dupla **Splash Brothers**, Stephen Curry e Klay Thompson, dois dos maiores arremessadores da história.

Do outro lado, o **Denver Nuggets de 2023**, campeão com um estilo completamente distinto: um ataque altamente estruturado ao redor de **Nikola Jokić**, uma das mentes ofensivas mais brilhantes que o basquete já viu.  
O famoso **2-man game** entre Jokić e Jamal Murray se tornou a identidade do time, mostrando uma forma de vencer que contrasta totalmente com a dos Warriors.

E foi aí que a dúvida surgiu de verdade:

- **Como times tão diferentes conseguem o mesmo resultado final?**  
- **Quais são as nuances compartilhadas por campeões tão distintos?**  
- **Existe um “DNA” comum entre eles?**

Com essas perguntas em mente, decidi iniciar este projeto em busca das respostas.
